# Groups UI mockups

These concept mockups explore the first-release Groups UI in GlideHero's current authenticated visual language.

- `desktop-profile-groups.png`: signed-in profile Groups card and pending invitation.
- `desktop-group-page.png`: members-only group standings, territory map, pilot filter, and flights.
- `mobile-profile-groups.png`: responsive profile Groups card and invitation actions.
- `mobile-group-page.png`: responsive group map, standings, and selected flight.

They are visual design references, not screenshots of implemented functionality.
